# 모델 선택형 로컬 웹

```bash
python -m pip install --upgrade fxbx
fxbx serve --port 8000
```

표시된 localhost 주소를 열면 FuryAwesome 카테고리와 최신 릴리스를 고를 수
있습니다. **서빙 시작**은 파일을 확인·다운로드하고 별도 SDK worker에 한 모델을
적재합니다. 기존 실행의 `/predict`, `/v1/chat/completions`, `/v1/models`, `/status`
주소도 같은 포트에서 유지합니다. `fxbx ui`도 같은 화면을 엽니다.

모델을 미리 지정하면 웹이 열릴 때 그 모델을 자동으로 적재합니다.

```bash
fxbx serve stabilityai/sdxl-turbo --port 8000
fxbx serve ./model.fxbx --port 8000
```

**호출 샘플**에서 서빙 재실행 명령과 Python HTTP 호출 코드를 복사합니다.
호출은 이미 적재된 worker를 재사용합니다. 입력·LoRA를 바꾸면 코드가 갱신됩니다.
기본은 LoRA 없이 실행하며, 지원 패키지는 접힌 **파인튜닝 · LoRA 추가 옵션**에서
등록 어댑터 또는 검사된 HF 어댑터를 선택할 수 있습니다. 전체 체크포인트를 임의로
교체하는 기능은 아닙니다.

```bash
fxbx serve ./model.fxbx --port 8000 --lora style-id=0.8
```

명시한 LoRA는 기본 요청과 웹의 초기 선택에 적용됩니다. 요청에 `loras: []`를
보내거나 웹에서 선택을 해제하면 기본 모델을 사용합니다. HF에서 가져온 ID는
**같은 서버의 해당 실행계약 캐시**에 보관되므로 다른 서버에는 먼저 가져와야 합니다.
알 수 없는 ID·강도는 거부하고 기본 모델로 조용히 대체하지 않습니다.

모델 전환은 현재 요청이 끝난 뒤 소유 worker를 해제하고 새 worker를 적재합니다.
다른 NPU 프로세스를 중지하지 않습니다. 잘못된 검색·입력 계약 거부와 전송/실행 실패를
구분하며, 실패한 SDK 세션은 다시 적재해야 합니다. 준비 중에만 브라우저가 상태를
확인하고, 평상시에는 지속 감시를 하지 않습니다.

서버는 loopback에만 열립니다. 원격에서는 SSH 포워딩을 사용하세요. 현재 Python 또는
사용자가 설정한 `FXBEX_WORKER_PYTHON`의 SDK를 사용합니다. 환경 누락은 화면에서
오류로 알려주며 웹에서 임의로 패키지 설치나 컴파일을 수행하지 않습니다.

원시 네이티브 실행 계획은 일반 파이프라인 패키지와 구분해 기존 `ExecutionFXB`
로더로 엽니다. 이 경우 샘플은 `*.sample.safetensors`의 실제 입력 텐서를 사용하며,
출력 텐서 전부를 safetensors로 저장하고 shape·dtype를 표시합니다. 이미지 파일이나
문장을 원시 텐서로 임의 변환하지 않습니다. 상태가 있는 네이티브 모델은 별도의
수명 관리 어댑터가 필요합니다. 생성된 HTTP 호출은 모델 식별자를 고정해, 다른 모델로
전환한 뒤 예전 샘플을 실행하면 거부합니다.

패키지 어댑터는 `validate_predict_inputs(payload)`를 제공해 토큰 길이·입력 형식 등
**상태를 바꾸지 않는 CPU 사전 검사**를 수행할 수 있습니다. 이 단계의 거부는 LoRA
교체와 NPU 실행 전에 반환하므로 서빙을 유지합니다. 임의의 실행 오류를 단순 입력
오류로 간주해 세션 실패를 숨기지는 않습니다.

### 다른 컴퓨터의 브라우저로 접속

NPU 서버에서 `fxbx serve --port 8000`을 실행한 뒤, **브라우저를 쓰는 컴퓨터**에서 다음 명령을 실행합니다. 이 컴퓨터에는 SDK나 NPU가 필요하지 않습니다.

```bash
fxbx tunnel user@npu-server --local-port 8000 --remote-port 8000
```

SSH 별칭도 됩니다. 터널이 열린 상태에서 `http://127.0.0.1:8000/`을 여세요. 일반 SSH 인증과 서버 키 검증을 그대로 사용합니다. 로컬 포트가 사용 중이면 `--local-port 18000`으로 바꾸고 18000번 주소를 엽니다. Ctrl-C는 터널만 종료하며 서버의 모델은 유지됩니다. fxbX가 없는 컴퓨터에서는 화면에 표시되는 동등한 `ssh -N -L ...` 명령을 복사하면 됩니다.

### 선별 LoRA 정보

모델별 추천의 원본은 FuryAwesome의 `lora-catalog.json`입니다. 제목·한국어 효용·제약·고정 HF 리비전·라이선스를 함께 표시하며, 런타임이 제공하는 실제 설치·선택 목록과 구분합니다. 현재 패키지가 HF 가져오기를 지원할 때만 가져오기 버튼이 활성화됩니다. 다운로드와 모든 텐서의 결합 검사를 통과한 뒤에도 자동 선택하지 않습니다. 기본 모델을 유지하며 사용자가 추가 옵션에서 선택합니다.
